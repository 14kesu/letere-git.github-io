对战斗系统进行一个从基础到完善的拆解

逐层拆解一个 Unity 3D 动作战斗原型，从输入到伤害的每一步代码实现

2026-06-11

一、项目概述

一个从空白 Unity 工程开始搭建的 3D 动作战斗原型。约 6,800 行 C#，88 个脚本文件，覆盖 13 个模块。所有系统从零设计实现，不使用战斗中间件或现成框架。

已实现的战斗功能：

  • 基于连招链的轻攻击（左键）和技能/大招（E/Q 键）
  • Shift 闪避→冲刺链路，支持闪避中触发的特殊攻击（闪A）
  • 双角色切换（Tab 普通切换 / QTE 连携切人）
  • 霸体/耐力值分支的受击与格挡动画
  • 自动敌人锁定与攻击判定（SphereCast + 距离角度过滤）

已实现的辅助系统：

  • Cinemachine + Timeline 技能相机（Dolly 路径推近变焦）
  • ComboData→ComboContainerData→PlayerComboSOData 三层 ScriptableObject 数据驱动
  • 事件系统解耦伤害链路
  • VFX/SFX 对象池
  • Timer 对象池计时器
  • CinemachineImpulse 震屏 + Animator.speed 顿帧（实现但调用被注释）

二、架构总览

设计核心理念

两个相互独立的有限状态机并行运转：

1
2
3

Player (MonoBehaviour)
  ├── movementStateMachine   ← 移动 FSM（待机/行走/奔跑/冲刺/闪避/转身…）
  └── comboStateMachine      ← 连招 FSM（Null/ATKIng/Skill）

两者通过 OnAnimationTranslation（Unity StateMachineBehaviour）联动，但互不包含引用——联动仅通过 Player 层的 OnAnimationTranslateEvent 中转。

事件系统的角色

所有伤害判定、特效、音效通过 GameEventManager（类型安全的泛型 Action 封装）广播。攻击者只管发事件，不管谁接。敌人 Health 组件监听 "触发伤害" 事件，做伤害、动画、特效、音效四件事。

public enum OnEnterAnimationPlayerState
{
    Idle, Walk, Run, Sprint,
    Dash, DashBack, TurnBack,

每个 Animator 动画状态上挂一个 OnAnimationTranslation，Inspector 中选对应的枚举值：

  • Dash / DashBack → 闪避动画
  • ATK → 普通攻击动画
  • Null → 技能动画（进入时不触发任何逻辑，退出时走 default 分支两者都调）
  • Switch / SwitchOut → 切人进出场

switch (onEnterAnimationState)
{
    case Dash / DashBack / TurnBack / Switch / SwitchOut
         / Idle / Walk / Run / Sprint:
        player.OnMovementAnimationExitEvent();   // 只调 movement
        break;

    case ATK:
        player.OnMovementAnimationExitEvent();   // 调 movement（恢复移动）
        player.OnComboAnimationExitEvent();      // 调 combo（退出攻击状态）
        break;

    default:  // 含 Null（技能动画）
        player.OnAnimationExitEvent();            // 两者都调（向后兼容）
        break;
}

踩过的坑

中间版本 ATK 分支只调了 combo 忘了调 movement → 攻击结束卡死在 PlayerMovementNullState 无法移动。修复后发现翻滚退出也同时触发了 combo FSM → 技能被打断。最终版加 default 分支向后兼容 Null 状态的技能动画，Dash 系列只调 movement。

  • comboIndex：当前连招段索引（0→1→2→0 循环）

Timeline 方案演进

整个过程走了六种方案，每种都有具体的失败原因：

尝试 方案 失败原因
1 Cinemachine Track（编辑器） Signal Emitter 在 Animator State 上搜不到
2 Animation Event + Object 参数 动画事件的 Object 字段不支持拖场景对象
3 Prefab Mode + Animation Track ExposedReferences 在 Prefab 上下文丢失
4 场景多 Director + 动画事件 同上，场景对象引用在 .anim 的 AnimationEvent 中不可序列化
5 PlayableDirector 放角色 Prefab + VCam 子物体 GetGenericBinding 返回 NULL，Prefab 实例化后绑定丢失
6 SkillTimelineManager 运行时自动补绑 ✅ 最终方案

// SkillTimelineManager.PlaySkillTimeline():
foreach (var track in timeline.GetOutputTracks())

IEnumerator WaitAttackFinishAndExit(SwitchCharacterInfo info, string switchOutAnim)
{
    while (info.animator.AnimationAtTag("ATK") || info.animator.AnimationAtTag("Skill"))
        yield return null;           // 每帧检查，攻击播完再继续

    info.animator.CrossFadeInFixedTime(switchOutAnim, 0.1f);
    StartDeactivateCoroutine();      // 延迟 switchOutCharacterTime 后隐藏
}

同时做了防护：如果同一角色被切出去后又切回来，ExecuteSwitchCharacter 中检查 waitAttackExitTarget == newCharacterInfo.character → StopCoroutine 取消旧协程，防止把退场动画覆盖到新登场动画上。

十七、补充细节

根运动（Root Motion）复用

CharacterMoveControllerBase.OnAnimatorMove() 根据当前动画 Tag 决定位移倍率：

1
2
3

if   (AnimationAtTag("Movement")) → Move(dir * deltaTime * moveMult)
elif (AnimationAtTag("Dodge"))    → Move(dir * deltaTime * dodgeMult)
// 其他 Tag 不移动

同一个移动逻辑通过 Tag 复用，不需要每个状态单独写一段位移代码。闪避动画设 "Dodge" Tag 走 dodge 倍率，步行/奔跑/冲刺动画设 "Movement" Tag 走各自的 inputMult 倍率。

ExpandClass.AnimationAtTag 扩展方法

整个项目中最高频的辅助方法，一行代码：

1
2

public static bool AnimationAtTag(this Animator animator, string tagName, int layerIndex = 0)
    => animator.GetCurrentAnimatorStateInfo(layerIndex).IsTag(tagName);

出现在：CanBaseComboInput 的不在 Hit/Parry/Skill 中才能攻击判断、AttackTrigger 的三路分支、PlayerMovementNullState.CheckStateExit 的"攻击中不能退出"守卫、CharacterHealthBase.LookAtAttacker 的"受击中才转脸"判断。Tag 在 Animator Controller 中设，不写在代码枚举里，加新 Tag 改 Animator 即可。

AnimatorID 参数哈希 

1
2
3

public static readonly int MovementID  = Animator.StringToHash("Movement");
public static readonly int HasInputID  = Animator.StringToHash("HasInput");
public static readonly int TurnBackID  = Animator.StringToHash("TurnBack");

字符串哈希避免每帧字符串比较的 GC。MovementID 被 HandInput() 每帧 SetFloat 驱动 Blend Tree；HasInputID 切换待机/移动动画混合；TurnBackID 触发转身动画。

PlayerMovementNullState.CheckStateExit 守卫

攻击/技能中，这个守卫防止动画退出时误切移动状态：

1
2
3
4
5
6
7
8

void CheckStateExit()
{
    if (AnimationAtTag("ATK") || AnimationAtTag("Skill"))
        return;   // 攻击还没播完，不退

    if (PlayerMove != zero) → ChangeState(runningState)
    else                    → ChangeState(idlingState)
}

没有这个守卫，每次攻击动画退出过渡都会触发移动状态迁移，导致攻击连不上下一段。
